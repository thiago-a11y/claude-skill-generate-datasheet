1. Six Answers in 60 Seconds

Seis respostas rápidas para decisão técnica

What is it?

Fábrica de 4 skills para Claude Code + ferramenta CLI offline (CodeDocs). Skills geram documentação, inteligência operacional e correções assistidas. CodeDocs faz o mesmo sem nuvem.

Where does it run?

Skills: dentro do Claude Code (nuvem Anthropic). CodeDocs: qualquer máquina com Python 3.6+ — 100% offline, zero rede.

How does data flow?

Skills: Claude Code lê SKILL.md e escaneia o codebase via grep/find/git. CodeDocs: mesmos scans, renderiza HTML localmente. Zero egress de dados.

Security?

Zero dependências, zero chamadas de rede, zero telemetria. Saída HTML com escaping. Licença BSL para uso comercial.

Integration?

Skills: instala via curl ou git clone no diretório .claude/skills/. CodeDocs: python3 -m codedocs /path.

What does IT provision?

Python 3.6+ para CodeDocs. Assinatura Claude Code para Skills. Nenhuma infra adicional.
